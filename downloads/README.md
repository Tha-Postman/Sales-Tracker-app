# Desktop Download

Do not commit the full Windows desktop package into this repository.

The packaged desktop app is generated at:

```txt
C:\Users\HP\SalesTrackerRelease\win-unpacked
```

Zip that folder and upload it to one of these:

- GitHub Releases
- Google Drive
- Cloudflare R2
- Supabase Storage
- Any static file host that supports large files

Then update the download link in `install.html`.

Current placeholder path:

```txt
downloads/SalesTracker-Windows.zip
```
